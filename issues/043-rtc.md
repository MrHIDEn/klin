# 043 — RTC → `Instant` (separate module)

**Status:** 💭 under consideration
**Depends on:** [010](010-bare-metal.md); nice to have [031](031-hal-libraries.md)

## Context

[037](037-datetime-format.md): `time.now()` = host wall clock (`CLOCK_REALTIME`).
MCU hardware clock / external chip **is not** `time.now()` — separate API
so the source is not guessed.

## Proposal

```klin
let t = rtc.read()   // → time.Instant
```

- HAL/board provides the read; result is the same `Instant` (unix ns) as in `time`
- format / parse stay in the `time` module

## What not to do

- Hiding RTC under `time.now()`.
- Mixing with FFI C libraries (021) / Klin packages (020) in one issue —
  here only the `rtc` + Instant contract.
- CPU cycles ([044](044-cpu-cycles.md)) in the `rtc` module.
