# 043 — RTC → `Instant` (osobny moduł)

**Status:** 💭 do rozważenia
**Zależy od:** [010](010-bare-metal.md); mile widziane [031](031-biblioteki-hal.md)

## Kontekst

[037](037-datetime-format.md): `time.now()` = wall host (`CLOCK_REALTIME`).
Zegar sprzętowy MCU / zewnętrzny chip **nie** jest `time.now()` — osobne API,
żeby nie zgadywać źródła.

## Propozycja

```klin
let t = rtc.read()   // → time.Instant
```

- HAL/board dostarcza odczyt; wynik to ten sam `Instant` (unix ns) co w `time`
- format / parse zostają w module `time`

## Czego nie robić

- Ukrywania RTC pod `time.now()`.
- Mieszania z FFI C libraries (021) / pakietami Klin (020) w jednym issue —
  tu tylko kontrakt `rtc` + Instant.
- Cyklów CPU ([044](044-cpu-cycles.md)) w module `rtc`.
