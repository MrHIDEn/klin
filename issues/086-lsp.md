# 086 — Language Server Protocol (`klin lsp`)

**Status:** 🔨 hover + definition on branch `feat/086-lsp` (MVP diagnostics/format ✅)
**Depends on:** 002 (checker), 033 (`klin fmt`)

## Goal

Thin Language Server in the **same** repo as the compiler — stdio JSON-RPC —
so editors can show diagnostics, format, hover, and go-to-definition without a
second parser.

## Done

- CLI: `klin lsp` (stdio)
- Document sync: `didOpen` / `didChange` / `didClose` (full text)
- Diagnostics from preprocess → lex → parse → check (one error at a time)
- `textDocument/formatting` → [`formatSource`](../lib/fmt.dart)
- `textDocument/hover` / `textDocument/definition` via `resolvedDef` on AST
  ([`lib/navigate.dart`](../lib/navigate.dart)); locals, fields, calls, methods
- Analysis facade: [`lib/analyze.dart`](../lib/analyze.dart)
- `Checker.check(..., {requireMain})` — CLI `true`; LSP `false`
