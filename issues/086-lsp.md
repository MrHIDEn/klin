# 086 — Language Server Protocol (`klin lsp`)

**Status:** ✅ MVP done (on branch `feat/086-lsp`; merge → keep ✅)
**Depends on:** 002 (checker), 033 (`klin fmt`)

## Goal

Thin Language Server in the **same** repo as the compiler — stdio JSON-RPC —
so editors can show diagnostics and format Klin sources without a second parser.

## MVP (done)

- CLI: `klin lsp` (stdio)
- Document sync: `didOpen` / `didChange` / `didClose` (full text)
- Diagnostics from preprocess → lex → parse → check (one error at a time;
  frontend is fail-fast)
- `textDocument/formatting` → [`formatSource`](../lib/fmt.dart)
- Analysis facade: [`lib/analyze.dart`](../lib/analyze.dart) (unit-tested)
- `Checker.check(..., {requireMain})` — CLI keeps `true`; LSP defaults `false`
  so library modules are editable without a fake `main`
