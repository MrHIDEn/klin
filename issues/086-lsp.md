# 086 — Language Server Protocol (`klin lsp`)

**Status:** 🔨 multi-error + `$fn` source maps on `feat/086-lsp`
**Depends on:** 002 (checker), 033 (`klin fmt`), 026 (preprocess)

## Goal

Thin Language Server in the **same** repo as the compiler — stdio JSON-RPC —
so editors can show diagnostics, format, hover, and go-to-definition without a
second parser.

## Done

- CLI: `klin lsp` (stdio)
- Document sync: `didOpen` / `didChange` / `didClose` (full text)
- Diagnostics from preprocess → lex → parse → check; check errors collected
  per function (`Checker.collectErrors`) so multiple body errors can appear
- `textDocument/formatting` → [`formatSource`](../lib/fmt.dart)
- `textDocument/hover` / `textDocument/definition` via `resolvedDef` on AST
  ([`lib/navigate.dart`](../lib/navigate.dart)); locals, fields, calls, methods
- `textDocument/completion` via [`lib/complete.dart`](../lib/complete.dart)
- [`SourceMap`](../lib/source_map.dart) from [`preprocessWithMap`](../lib/preprocess.dart):
  diagnostics / nav / completion use editor coordinates after `$fn` expand
- Analysis facade: [`lib/analyze.dart`](../lib/analyze.dart)
- `Checker.check(..., {requireMain, collectErrors})` — CLI defaults; LSP
  `requireMain: false`, `collectErrors: true`
